## 📖 About EdgeDock
**EdgeDock** is a next-generation Android multitasking assistant and floating sidebar suite developed by **StrawHats Studios**. It brings desktop-grade productivity and instant tool triggers to any Android screen without interrupting your active workflow.

---

## ✨ Features

- 🚀 **Floating Edge Dock:** Seamless swipe-activated edge bar with custom placement and neon glow.
- 🎛️ **Assistive Touch Controller:** Draggable floating action button with quick navigation and system shortcuts.
- ⚡ **RAM & Speed Booster:** Live memory gauge and one-tap cache flush.
- 🔊 **Fine-Grained Volume Hub:** Media, Ring, Notification, and Alarm sliders with quick mute presets.
- ☀️ **Brightness & Screen Control:** Precision brightness adjustment and screen timeout management.
- 🎨 **Visual Theme Customizer:** Cyberpunk Neon, Emerald Pulse, Sunset Blaze, and AMOLED Midnight styling.
- 🔄 **In-App GitHub OTA Updates:** Automatic update checks and release installation right inside the app.
